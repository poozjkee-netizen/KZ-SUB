# Changelog

Все значимые изменения проекта NP SUB. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

Проект состоит из трёх деплой-единиц, поэтому изменения помечаются областью:
**[Панель]** (версионируется, требует новой `.zxp`), **[Шлюз]** (деплой на Fly),
**[Воркер]** (образ Runpod). Версия в заголовке — это версия **панели**
(`ExtensionBundleVersion`).

## [Unreleased]

_Изменения, ещё не вошедшие в подписанную `.zxp` / не задеплоенные._

- [Шлюз] Каталог тарифов `app/plans.py` — единый источник (цена/минуты/срок).
  `licenses.create_from_plan` выдаёт лицензию по тарифу — шов под будущий вебхук оплаты.
- [Шлюз] Тарифная сетка упрощена перед первыми продажами до двух пунктов:
  **Demo** (бесплатно, 3 мин, без срока) и **Standard** ($3 / 1 490 ₸, 60 мин
  **или** 30 дней — что раньше). Прежняя многотирная сетка (Free/Starter/
  Creator/Pro/Studio + Minute Pack) убрана из `plans.py` — при росте спроса
  можно вернуть, добавив записи обратно.
- [Шлюз] CLI лицензий: выдача `create --plan standard`, каталог `plans`,
  удаление `delete <ключ>` и `purge-revoked` (снести все отозванные).
- [Проект] `docs/DISTRIBUTION.md`: runbook ручных продаж через Kaspi (оплата →
  `create --plan` → выдача ключа) и управление лицензиями; имя `.zxp` с версией.

## [1.2.0] — 2026-07-23

_Полная локализация интерфейса, гейт активации с прогрессом обработки,
коммерческая система лицензий и юнит-экономика._

- [Проект] Профессионализация репозитория: `CLAUDE.md`, `CHANGELOG.md`,
  `LICENSE`, `docs/DECISIONS.md`, `docs/RELEASE_PROCESS.md`, `docs/README.md`,
  `backend/.env.example`, `backend/pytest.ini`, CI. Заголовки доков выровнены на «NP SUB».
- [Воркер] Финальная рабочая схема надёжности Runpod (ADR-13): лёгкий образ
  `kzsub-runpod:v2` без вшитых весов, БЕЗ Network Volume, Data Centers = Any + все
  24GB-карты, FlashBoot ON. GPU стал «High Supply», прогон ~20–30 с. Проверено на проде.
- [Проект] `docs/HOSTING.md`: раздел «Troubleshooting: 502 и 403» — пересозданный
  эндпоинт требует обновить `KZSUB_RUNPOD_ENDPOINT_ID`; Runpod-ключ должен быть Read/Write.
- [Панель] Гейт активации при первом запуске: без введённого ключа основной
  интерфейс недоступен; ключ сохраняется и больше не спрашивается; сменить — в Настройках.
- [Панель] Прогресс обработки по этапам (подготовка → экспорт → загрузка →
  распознавание → создание → импорт) с процентами; реальные «якоря» + докрут на распознавании.
- [Панель] Выбор языка вынесен из настроек в шапку; убраны логотип и хэндл Instagram.
- [Панель] В режиме настроек кнопка «Создать субтитры» скрывается, внизу — «powered by danik np».
- [Панель] Полноценная локализация интерфейса вместо чередования языков:
  единый словарь `plugin/js/i18n.js` (ru/kk), выбор «Язык интерфейса» в
  Настройках сохраняется и восстанавливается; все строки — через `I18N.t()`,
  `host.jsx` возвращает коды ошибок (текст в словаре). Готово к добавлению en.
- [Панель] Разделены язык субтитров (шапка: казахский; скоро кыргызский,
  узбекский) и язык интерфейса (настройки). Шестерёнка больше не «прыгает».
- [Шлюз] Система лицензий на постоянном хранилище (`app/licenses.py`, SQLite на
  томе) вместо заглушки `quota.py` (учёт в памяти): типы developer/trial/
  subscription/minute_pack/lifetime с полями id/api_key/email/type/created_at/
  expires_at/total_minutes/used_minutes/status. Проверка на каждом запросе:
  существование ключа, статус, срок, лимит минут. Ответ несёт `X-Minutes-Remaining`.
- [Шлюз] **Удалены тестовые ключи** (`dev-key`/`free-demo`). Developer-ключ —
  через `KZSUB_DEVELOPER_KEY`. CLI выдачи: `python -m app.licenses …`.
- [Воркер] Лицензии проверяет только шлюз; воркер принимает лишь доверенный
  внутренний ключ (`KZSUB_RUNPOD_WORKER_KEY`) и транскрибирует.
- [Проект] Юнит-экономика и тарифы Free/Starter/Creator/Pro/Studio в
  `docs/MONETIZATION.md`; задел под регистрацию/кабинет/оплату/смену тарифа.
- [Шлюз] Эндпоинт `GET /license` — read-only статус лицензии (active/status/
  type/остаток минут) по ключу; основа для «Проверить» и будущего кабинета.
- [Панель] Кнопка «Проверить» теперь валидирует сам ключ (а не только
  доступность сервера): показывает «Ключ активен · осталось N мин» или причину
  (неверный/истёк/лимит/заблокирован). Активация тоже проверяет ключ на сервере
  до входа — неверный ключ больше не пускает в интерфейс.

## [1.0.0] — 2026-07-21

Первый цельный релиз: рабочий продукт от панели до прода.

### Панель
- Минималистичный UI: одна кнопка, чёрная тема с неоновыми градиент-блобами,
  светящийся спиннер, настройки за шестерёнкой.
- Бренд «@np3_player», имя расширения «NP SUB», иконка вкладки.
- Ротация надписи кнопки каз ⇄ рус (капс, bold), цитаты во время обработки.
- Двуязычные статусы (каз ⇄ рус каждые 5с) и подсказки терпения при долгом ответе.
- Авто-вставка субтитров на дорожку через `createCaptionTrack` (с откатом в корзину).
- Отпечаток устройства (`X-Device-Id`) для анти-шаринга.
- Вшитый аудио-пресет 16 kHz mono (ноль настроек у пользователя).

### Шлюз (backend)
- FastAPI: `POST /transcribe` (multipart → `.srt`/JSON), `GET /health`.
- Два режима: локальный Whisper и прокси в Runpod (`runpod_client`).
- Нарезка субтитров: караоке `word` (по слову, предлоги прилипают) и `phrase`.
- Оформление: ВЕРХНИЙ регистр, удаление пунктуации (кроме `!`).
- Ключи из `KZSUB_API_KEYS`, квоты, привязка ключа к устройствам (`devices`).
- Контейнеризация (Dockerfile CPU/GPU/gateway), `fly.toml`, том `kzsub_data`.

### Воркер (serverless)
- Runpod-обработчик: аудио(base64) → транскрибация → нарезка/стиль → `.srt`.
- Веса модели: переход на Network Volume для быстрых холодных стартов.

### Тесты
- Dep-free: `srt`, `quota`, `segmentation`, `style`, `devices`.
- Интеграционный: `test_api` (HTTP-контракт с замоканной моделью).
