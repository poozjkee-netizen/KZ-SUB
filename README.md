# KZ-SUB — авто-субтитры на казахском для Adobe Premiere Pro

Плагин для Premiere Pro, который автоматически распознаёт **казахскую речь** и
вставляет субтитры в таймлайн. Premiere «из коробки» не транскрибирует казахский —
это и есть проблема, которую решает продукт.

## Как это устроено

```
┌─────────────────────────┐        ┌──────────────────────────────┐
│   Панель в Premiere      │        │       Бэкенд (KZ-SUB API)     │
│   (CEP, HTML/JS/JSX)     │        │       FastAPI + Whisper       │
│                          │        │                              │
│ 1. Выгружает аудио  ─────┼───────▶│ 2. Транскрибирует казахский   │
│    из активной секвенции │  POST  │    (faster-whisper, kk)       │
│                          │        │ 3. Сегменты → .srt            │
│ 5. Импортирует .srt  ◀───┼────────┤ 4. Возвращает .srt + JSON     │
│    как дорожку субтитров │        │    (+ учёт квоты/подписки)    │
└─────────────────────────┘        └──────────────────────────────┘
```

Ядро продукта — **не плагин, а движок распознавания казахского**. Плагин лишь
удобная обёртка внутри Premiere. Качество ASR = ценность, за которую платят.

## Структура репозитория

| Папка        | Что внутри                                                        |
|--------------|-------------------------------------------------------------------|
| `backend/`   | API транскрибации: приём аудио → казахский текст с тайм-кодами → SRT |
| `plugin/`    | CEP-панель для Premiere Pro (UI, выгрузка аудио, импорт субтитров) |
| `docs/`      | Архитектура, монетизация, roadmap                                 |

## Быстрый старт (разработка)

### Бэкенд
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
Проверка: `curl -F "file=@sample_kz.wav" -H "X-API-Key: dev-key" http://localhost:8000/transcribe -o out.srt`

### Плагин
См. [`plugin/README.md`](plugin/README.md) — установка CEP-панели в режиме
разработки (включение debug-режима CEP и симлинк в папку расширений Adobe).
