========================================================
  NP SUB — установка панели субтитров для Premiere Pro
========================================================

В этой папке:
  • NP-SUB               — файлы панели (не трогайте)
  • install-windows.bat  — установщик для Windows
  • install-macos.command — установщик для macOS

--------------------------------------------------------
WINDOWS
--------------------------------------------------------
1. Закройте Premiere Pro, если он открыт.
2. Дважды кликните по файлу  install-windows.bat
   (если Windows покажет «SmartScreen» — «Подробнее» →
    «Выполнить в любом случае»; права администратора НЕ нужны).
3. Дождитесь надписи «Готово!» и нажмите любую клавишу.
4. Откройте Premiere Pro → меню Window → Extensions → NP SUB.
5. Введите ключ активации.

--------------------------------------------------------
macOS
--------------------------------------------------------
1. Закройте Premiere Pro, если он открыт.
2. Дважды кликните по файлу  install-macos.command
   Если macOS напишет, что файл «от неустановленного
   разработчика» — кликните по нему ПРАВОЙ кнопкой →
   «Открыть» → «Открыть».
3. Дождитесь надписи «Готово!» и нажмите Enter.
4. Откройте Premiere Pro → меню Window → Extensions → NP SUB.
5. Введите ключ активации.

--------------------------------------------------------
ИСПОЛЬЗОВАНИЕ
--------------------------------------------------------
Откройте секвенцию с казахской речью и нажмите
«СУБТИТР ЖАСАУ» — через несколько секунд субтитры
появятся на новой дорожке.

--------------------------------------------------------
ЕСЛИ ПАНЕЛИ НЕТ В СПИСКЕ EXTENSIONS
--------------------------------------------------------
• Убедитесь, что Premiere полностью перезапущен.
• Запустите установщик ещё раз.
• Напишите в поддержку — поможем.
