# Roadmap

Статусы: ✅ готово (в этом каркасе) · 🔨 следующее · 🔮 позже

## Этап 0 — Каркас MVP (текущий)
- ✅ Бэкенд FastAPI: `POST /transcribe` (аудио → `.srt`/JSON)
- ✅ Транскрибация на faster-whisper, язык `kk`, VAD
- ✅ Формирование SRT + юнит-тесты
- ✅ Заглушка квоты/ключей
- ✅ CEP-панель: UI, экспорт аудио, загрузка, импорт `.srt`
- ✅ Документация (архитектура, монетизация)

## Этап 1 — Рабочий сквозной прогон
- ✅ `CSInterface.js` встроен (минимальный шим) — внешняя загрузка не нужна
- ✅ Выбор аудио-пресета `.epr` прямо в панели (без копирования в папку)
- ✅ Кнопка «Тест» (проверка `/health`) + таймауты + обработка сетевых ошибок
- ✅ Интеграционный тест `/transcribe` (multipart → SRT, модель замокана)
- ✅ Dep-free тесты (srt, quota) — прогоняются без тяжёлых зависимостей
- ✅ Скрипты установки (macOS/Windows) + запуска бэкенда + runbook первого прогона
- 🔨 Проверить панель в реальном Premiere (экспорт → API → импорт)
- 🔨 Тестовые казахские аудио-сэмплы + замер WER `large-v3` baseline
- 🔨 Прогресс-индикатор реального прогресса (сейчас — этапы 1/2/3)

## Этап 2 — Качество казахского (главный приоритет)
- 🔨 Постобработка: восстановление пунктуации, нормализация
- 🔮 Сравнение с Yandex SpeechKit (kk-KZ) и ISSAI Soyle
- 🔮 Fine-tuning Whisper на Kazakh Speech Corpus (KSC2)
- 🔮 Пользовательский словарь (имена, термины канала)

## Этап 3 — Продукт и удобство
- ✅ Разбивка длинных реплик по длине строки/времени/паузам (пословные тайм-коды)
- ✅ Караоке-стиль «одно слово на реплику» + прилипание предлогов (стиль по умолчанию)
- ✅ ВЕРХНИЙ регистр / удаление пунктуации (переключатели)
- ✅ Авто-вставка на новую верхнюю видеодорожку (недеструктивно, откат в корзину при сбое) — требует проверки по версиям Premiere
- 🔮 Редактор субтитров прямо в панели (правка перед вставкой)
- 🔮 Выбор части секвенции (in/out) вместо всей

## Этап 4 — Хостинг, масштаб и биллинг
- ✅ Контейнеризация (Dockerfile CPU + GPU, docker-compose)
- ✅ API-ключи из окружения (KZSUB_API_KEYS) вместо захардкоженных
- ✅ Гайд по хостингу (serverless-GPU / VPS) — docs/HOSTING.md
- ✅ Прокси-режим шлюза (панель → CPU-шлюз → Runpod GPU), Dockerfile.gateway
- 🔨 Поднять шлюз + Runpod-эндпоинт на публичном HTTPS (шаги в HOSTING.md)
- 🔨 Реальная аутентификация (пользователи, токены) + регистрация на сайте
- 🔨 Постоянная квота (Postgres/Redis) + связка с подпиской (Kaspi/Stripe)
- 🔨 Очередь задач + пул GPU-воркеров + автоскейл
- 🔮 Объектное хранилище + пресайн-URL для больших файлов
