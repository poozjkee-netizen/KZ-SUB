# Runbook: первый запуск в Premiere Pro

Цель — проверить работоспособность всей цепочки: секвенция → аудио → сервер →
казахские субтитры → импорт в проект. Займёт ~15 минут (плюс первая загрузка
весов модели).

## Что понадобится
- Premiere Pro (2020+) с открытым проектом и **секвенцией с казахской речью**.
- Python 3.9+ на той же машине.
- ~5 ГБ свободного места (веса `large-v3` ≈ 3 ГБ качаются один раз).

---

## Шаг 1. Установить панель

**macOS:**
```bash
bash scripts/install-macos.sh
```
**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-windows.ps1
```
Скрипт включает debug-режим CEP и линкует папку `plugin/` в директорию
расширений Adobe. После него **полностью перезапустите Premiere**.

## Шаг 2. Запустить бэкенд

**macOS/Linux:**
```bash
bash scripts/run-backend.sh
```
**Windows:**
```bat
scripts\run-backend.bat
```
Дождитесь строки `Uvicorn running on http://127.0.0.1:8000`. Оставьте окно
открытым — это ваш сервер.

> Первый запуск может «висеть» на загрузке весов модели при **первом**
> `/transcribe` — это нормально, качается ~3 ГБ. Health-проверка (шаг 4)
> отвечает сразу, не дожидаясь весов.

## Шаг 3. Создать аудио-пресет `.epr` (один раз)

Premiere не умеет экспортировать секвенцию без пресета.
1. **File → Export → Media** (любая секвенция).
2. **Format: Waveform Audio (WAV)**, желательно **16 kHz, mono**.
3. Кликните **Save Preset**, назовите (напр. `KZSUB Audio 16k`), запомните,
   куда сохранился `.epr` (или сразу сохраните в удобную папку).

## Шаг 4. Открыть панель и проверить связь

1. Premiere → **Window → Extensions → «KZ-SUB — қазақша субтитр»**.
2. В панели:
   - **API URL:** `http://localhost:8000` (по умолчанию уже стоит).
   - **API-кілт:** `dev-key`.
3. Нажмите **«Тест»**. Ожидаемо: зелёная строка
   `Сервер жұмыс істеп тұр · модель: large-v3 · тіл: kk`.
   Если ошибка — см. траблшутинг ниже.

## Шаг 5. Прогнать субтитры

1. Кнопкой **«Таңдау»** выберите созданный `.epr`.
2. Откройте нужную **секвенцию** (активной должна быть именно она).
3. Нажмите **«Субтитр жасау»**. Панель пройдёт этапы 1/3 → 2/3 → 3/3.
4. Результат: `.srt` импортируется в **бин проекта** как ассет субтитров.
   Перетащите его на таймлайн — субтитры появятся на видео.

## Траблшутинг

| Симптом | Причина / решение |
|---|---|
| Панели нет в меню Extensions | Premiere не перезапущен; или debug-режим не включился для вашей версии CSXS. Перезапустите Premiere; переустановите скрипт установки. |
| Панель белая/пустая | Не загрузился `CSInterface.js` или JS-ошибка. Откройте DevTools: браузер → `http://localhost:8088` (порт из `.debug`) при запущенном Premiere. |
| «Байланыс жоқ» на «Тест» | Бэкенд не запущен или не тот адрес. Проверьте окно из шага 2 и что URL = `http://localhost:8000`. |
| «Қате API-кілт (401)» | В поле ключа должно быть `dev-key`. |
| «Аудио-пресет табылмады» | Не выбран `.epr`. Нажмите «Таңдау» (шаг 5.1). |
| Экспорт вернул ERROR про activeSequence | Нет активной секвенции — кликните по секвенции, чтобы она стала активной. |
| Экспорт долго/не создаёт WAV | Проверьте, что пресет — именно **аудио** (WAV). Видео-пресет не подойдёт. |
| Транскрибация очень медленная | На CPU `large-v3` медленный. Для проверки цепочки можно временно поднять сервер с `KZSUB_WHISPER_MODEL=small` (качество ниже). На проде — GPU (`KZSUB_DEVICE=cuda`). |
| Субтитры не на казахском/мусор | Убедитесь, что в аудио действительно казахская речь; язык на сервере зафиксирован `kk`. |

## Отладка панели (DevTools)
При включённом debug-режиме и запущенном Premiere откройте в обычном браузере
**http://localhost:8088** — это Chrome DevTools панели (консоль, сеть, ошибки).
Порт задан в `plugin/.debug`.

## Что проверяем этим прогоном
- ExtendScript-экспорт аудио секвенции (`exportAsMediaDirect`) в вашей версии Premiere.
- Загрузка на сервер и качество казахского на реальном материале.
- Импорт `.srt` обратно (`importFiles`).

Если какой-то из трёх шагов падает — пришлите текст ошибки из панели (и, если
есть, из DevTools-консоли): по нему видно, какой именно вызов Premiere API
повёл себя иначе в вашей версии.
