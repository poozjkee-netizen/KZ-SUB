# Архив документации

Сюда переносятся **завершённые или устаревшие** документы задач, чтобы не
засорять активную структуру, но и не терять историю.

## Как пользоваться

- Задача из [`../tasks/`](../tasks/) полностью выполнена (Definition of Done
  достигнут) → перенеси её файл сюда и убери из активных таблиц
  [`../PROJECT.md`](../PROJECT.md).
- Документ устарел, но важен как история решений → сюда же (решения по существу —
  дублируй в [`../DECISIONS.md`](../DECISIONS.md)).
- Ничего не удаляем безвозвратно — архив хранит контекст «почему так сложилось».

Пока пусто — активные задачи в [`../tasks/`](../tasks/), индекс — в
[`../PROJECT.md`](../PROJECT.md).
