# VIDEO BRIEF — ссылка на ролик → транскрипция → разбор и сценарий

Инструмент для работы с чужим виральным контентом: даёшь ссылку — получаешь
расшифровку ролика, разбор «почему это смотрят» и готовый черновик **своего**
сценария по той же схеме. Ролик может быть на любом языке, **разбор всегда на
русском**.

Живёт в [`tools/videobrief/`](../tools/videobrief/). Это **не часть NP SUB**: он
не деплоится ни на Fly, ни на Runpod и запускается руками с твоей машины
(см. [ADR-17](DECISIONS.md)).

## Как работает

```
ссылка → yt-dlp → [субтитры ролика]  ─┐
                  [аудио → Whisper]  ─┴→ чистка текста → Claude → brief.md
```

1. **Метаданные** ролика берутся одним запросом yt-dlp (название, автор,
   длительность, просмотры, описание).
2. **Текст.** Сначала пробуем готовые субтитры автора — это секунды вместо минут
   распознавания. Нет субтитров — скачивается только аудиодорожка и распознаётся
   Whisper с авто-детектом языка.
3. **Чистка.** Авто-субтитры площадок идут «бегущей строкой» с повторами — они
   схлопываются; короткие реплики склеиваются в блоки по ~12 секунд, чтобы текст
   читался и экономил контекст модели.
4. **Разбор.** Claude получает метаданные и расшифровку с тайм-кодами и отвечает
   по жёсткой структуре (см. ниже).

## Установка

```bash
pipx install yt-dlp            # или brew install yt-dlp
brew install ffmpeg            # нужен только для распознавания звука
pip install -r tools/videobrief/requirements.txt
export ANTHROPIC_API_KEY=...   # ключ для разбора
```

`faster-whisper` уже стоит, если ты ставил `backend/requirements.txt`.

## Запуск

```bash
# обычный случай
python -m tools.videobrief "https://www.youtube.com/watch?v=..."

# TikTok/Reels: субтитров нет — распознаём звук
python -m tools.videobrief "https://www.tiktok.com/@user/video/123"

# только расшифровка + готовый промпт, без обращения к модели
python -m tools.videobrief "<ссылка>" --no-analysis

# свой файл или своя расшифровка
python -m tools.videobrief ролик.mp4
python -m tools.videobrief ролик.mp4 --transcript субтитры.srt
```

Результат — папка `out/briefs/<имя-ролика>/`:

| Файл | Что внутри |
|---|---|
| `brief.md` | разбор: о чём ролик, структура, каркас, свой черновик сценария |
| `transcript.txt` | чистый текст ролика, как сказано, без тайм-кодов |
| `transcript.timed.txt` | тот же текст с тайм-кодами |
| `prompt.txt` | задание, которое ушло модели — можно поправить и прогнать снова |
| `meta.json` | метаданные ролика и чем он расшифрован |

## Что именно отвечает модель

`brief.md` всегда идёт по одной структуре — так разборы разных роликов можно
сравнивать между собой:

1. О чём ролик.
2. Паспорт ролика (формат, ниша, аудитория, тон, CTA).
3. Почему это смотрят — хук, удержание, эмоции, петля.
4. Структура по блокам таблицей с тайм-кодами.
5. Сценарий целиком на русском.
6. Каркас для повторного использования — формула и шаблон.
7. Как сделать свою версию: 3 варианта хука, своя тема, усиление концовки.
8. Черновик своего сценария с хронометражом и подсказками по картинке.
9. Чего не копировать.

## Ключи командной строки

| Ключ | Зачем |
|---|---|
| `--audience "..."` | под кого делаем свою версию (по умолчанию — русскоязычная аудитория СНГ) |
| `--mode auto\|subs\|asr` | откуда брать текст: как получится / только субтитры / только распознавание |
| `--auto-subs` | разрешить авто-субтитры площадки: быстро, но без пунктуации |
| `--transcript ФАЙЛ` | взять готовую расшифровку (`.vtt`/`.srt`/`.txt`) |
| `--lang kk` | язык речи для Whisper (по умолчанию — авто-детект) |
| `--model`, `--effort`, `--max-tokens` | модель и глубина разбора |
| `--whisper`, `--device`, `--compute-type` | параметры распознавания |
| `--no-analysis` | не звать модель: только расшифровка и промпт |
| `--keep-audio` | не удалять скачанное аудио и субтитры |

## Переменные окружения

Префикс свой — `VIDEOBRIEF_`, чтобы настройки утилиты не смешивались с
`KZSUB_`-конфигом шлюза.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ для разбора (без него — только `--no-analysis`) |
| `VIDEOBRIEF_MODEL` | `claude-opus-5` | модель разбора |
| `VIDEOBRIEF_EFFORT` | `high` | глубина рассуждений |
| `VIDEOBRIEF_MAX_TOKENS` | `32000` | потолок длины разбора |
| `VIDEOBRIEF_TARGET_LANG` | `ru` | язык выдачи |
| `VIDEOBRIEF_WHISPER_MODEL` | `large-v3` | модель распознавания |
| `VIDEOBRIEF_DEVICE` | `cpu` | `cpu` \| `cuda` |
| `VIDEOBRIEF_COMPUTE_TYPE` | `int8` | `int8` (cpu) \| `float16` (gpu) |
| `VIDEOBRIEF_OUT_DIR` | `out/briefs` | куда складывать результаты |
| `VIDEOBRIEF_SUB_LANGS` | `ru,en,kk` | приоритет языков готовых субтитров |
| `VIDEOBRIEF_YTDLP` | `yt-dlp` | путь к yt-dlp, если он не в `PATH` |

## Тесты

Логика без сети и без тяжёлых пакетов закрыта тестами:

```bash
python tools/videobrief/tests/test_transcript.py
python tools/videobrief/tests/test_captions.py
python tools/videobrief/tests/test_pipeline.py
```

Скачивание, распознавание и вызов модели автотестами не покрыты — они требуют
сети и денег; проверяются вручную на одном коротком ролике.

## Частые грабли

- **«Не найден yt-dlp»** — поставь его; площадки меняют выдачу, поэтому обновляй
  (`pipx upgrade yt-dlp`), когда ссылка вдруг перестала открываться.
- **Ролик без субтитров и без ffmpeg** — аудио не вытащить; поставь ffmpeg.
- **Долгое распознавание** — на CPU минута речи считается минутами. Для коротких
  виральных роликов это нормально; для длинных бери `--auto-subs` или GPU
  (`--device cuda --compute-type float16`).
- **Разбор оборвался на лимите длины** — подними `VIDEOBRIEF_MAX_TOKENS` и
  прогони повторно по уже готовой расшифровке: `--transcript .../transcript.timed.txt`.
- **Текст ролика — это чужой текст.** Инструмент даёт разбор и каркас, а не
  разрешение копировать дословно; раздел «Чего не копировать» в `brief.md` про это.
