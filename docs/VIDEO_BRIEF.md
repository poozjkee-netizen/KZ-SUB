# NP Brief — приложение для Mac: ссылка на ролик → разбор и свой сценарий

Отдельная программа (не часть NP SUB): вставляешь ссылку на ролик — YouTube,
Instagram, TikTok — и получаешь расшифровку, разбор «почему это смотрят» и
готовый черновик **своего** сценария по той же схеме. Ролик может быть на любом
языке, **разбор всегда на русском**.

Код — в [`tools/videobrief/`](../tools/videobrief/). Ни Fly, ни Runpod, ни панель
не затронуты (см. [ADR-17](DECISIONS.md)).

## Установка (один раз, ~5 минут)

В Терминале, из папки репозитория:

```bash
bash scripts/install-np-brief-mac.sh
```

Скрипт создаёт отдельное окружение Python, ставит `yt-dlp`, `anthropic` и
`faster-whisper`, копирует программу в `~/Library/Application Support/NP Brief`
и собирает **`~/Applications/NP Brief.app`**. Больше Терминал не нужен.

Повторный запуск того же скрипта = обновление программы.

Если не окажется `python3`, macOS сама предложит поставить инструменты
разработчика — либо выполни `xcode-select --install`.

## Как пользоваться

1. Открой **NP Brief** двойным кликом (лежит в `~/Applications`, находится через
   Spotlight по имени). Откроется окно программы в браузере.
2. Первый раз: нажми **⚙︎** и вставь ключ Anthropic (`sk-ant-…`). Он сохраняется
   на твоём маке, в репозиторий не попадает. Там же задаётся аудитория, папка для
   результатов и модель распознавания.
3. Вставь ссылку на ролик → **Разобрать**.
4. Готовый разбор — в окне (вкладки «Разбор», «Чистый текст», «С тайм-кодами»),
   кнопки «Скопировать» и «Показать в Finder».

Файлы каждого ролика складываются в `~/Movies/NP Brief/<ролик>/`:

| Файл | Что внутри |
|---|---|
| `brief.md` | разбор: о чём ролик, почему его смотрят, структура, каркас, свой черновик |
| `transcript.txt` | чистый текст ролика, как сказано, без тайм-кодов |
| `transcript.timed.txt` | тот же текст с тайм-кодами |
| `prompt.txt` | задание, ушедшее модели — можно поправить и прогнать снова |
| `meta.json` | метаданные ролика и чем он расшифрован |

**Без ключа Anthropic** программа всё равно работает: делает расшифровку и
кладёт `prompt.txt`, который можно вставить в чат с моделью руками.

## Что происходит внутри

```
ссылка → yt-dlp → [субтитры ролика]  ─┐
                  [аудио → Whisper]  ─┴→ чистка текста → Claude → brief.md
```

1. **Метаданные** ролика берутся одним запросом yt-dlp (название, автор,
   длительность, просмотры, описание).
2. **Текст.** Сначала берутся готовые субтитры ролика — это секунды вместо минут
   распознавания (у YouTube они есть почти всегда). Нет субтитров — скачивается
   только аудиодорожка и распознаётся Whisper с авто-детектом языка (случай
   Instagram и TikTok).
3. **Чистка.** Авто-субтитры идут «бегущей строкой» с повторами — они
   схлопываются; короткие реплики склеиваются в блоки по ~12 секунд.
4. **Разбор.** Claude получает метаданные и расшифровку с тайм-кодами и отвечает
   по жёсткой структуре — одинаковой для всех роликов, чтобы разборы можно было
   сравнивать между собой.

Структура `brief.md`: о чём ролик → паспорт (формат, ниша, аудитория, тон, CTA) →
почему это смотрят (хук дословно, удержание, эмоции, петля) → структура по блокам
таблицей с тайм-кодами → сценарий целиком на русском → каркас-формула с
пропусками → как сделать свою версию (3 варианта хука, своя тема, усиление
концовки) → черновик своего сценария с хронометражом → чего не копировать.

## Сколько ждёт человек

| Случай | Время |
|---|---|
| YouTube с субтитрами | ~10 секунд на текст + 1-2 минуты на разбор |
| Instagram/TikTok, ролик до минуты, Whisper на CPU | 1-3 минуты на текст + разбор |
| Длинный ролик без субтитров | распознавание идёт примерно в реальном времени |

Ускорить распознавание: в настройках выбрать модель `medium` или `small`.

## То же самое из командной строки

Приложение и командная строка зовут один и тот же конвейер
(`tools/videobrief/pipeline.py`), поэтому результат одинаковый:

```bash
python -m tools.videobrief "https://www.youtube.com/watch?v=..."   # обычный прогон
python -m tools.videobrief "<ссылка>" --no-analysis                # только расшифровка
python -m tools.videobrief ролик.mp4 --transcript субтитры.srt     # свой файл
```

| Ключ | Зачем |
|---|---|
| `--audience "..."` | под кого делаем свою версию |
| `--mode auto\|subs\|asr` | откуда брать текст: как получится / только субтитры / только распознавание |
| `--no-auto-subs` | не брать авто-субтитры площадки (они без пунктуации) |
| `--transcript ФАЙЛ` | взять готовую расшифровку (`.vtt`/`.srt`/`.txt`) |
| `--lang kk` | язык речи для Whisper (по умолчанию — авто-детект) |
| `--model`, `--effort`, `--max-tokens` | модель и глубина разбора |
| `--whisper`, `--device`, `--compute-type` | параметры распознавания |
| `--no-analysis` | не звать модель: только расшифровка и промпт |
| `--keep-audio` | не удалять скачанное аудио и субтитры |

## Настройки и где что лежит

Окно программы хранит настройки (включая ключ) в
`~/Library/Application Support/NP Brief/settings.json` с правами `600`.
Командная строка читает переменные окружения с префиксом `VIDEOBRIEF_` — свой,
чтобы не смешиваться с `KZSUB_`-конфигом шлюза.

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ для разбора в режиме командной строки |
| `VIDEOBRIEF_MODEL` | `claude-opus-5` | модель разбора |
| `VIDEOBRIEF_EFFORT` | `high` | глубина рассуждений |
| `VIDEOBRIEF_MAX_TOKENS` | `32000` | потолок длины разбора |
| `VIDEOBRIEF_TARGET_LANG` | `ru` | язык выдачи |
| `VIDEOBRIEF_WHISPER_MODEL` | `large-v3` | модель распознавания |
| `VIDEOBRIEF_DEVICE` | `cpu` | `cpu` \| `cuda` |
| `VIDEOBRIEF_COMPUTE_TYPE` | `int8` | `int8` (cpu) \| `float16` (gpu) |
| `VIDEOBRIEF_OUT_DIR` | `out/briefs` | куда складывать результаты (командная строка) |
| `VIDEOBRIEF_SUB_LANGS` | `ru,en,kk` | приоритет языков готовых субтитров |
| `VIDEOBRIEF_YTDLP` | `yt-dlp` | путь к yt-dlp, если он не в `PATH` |
| `VIDEOBRIEF_STATE_DIR` | папка поддержки | где лежат настройки приложения |

## Безопасность

Окно программы — локальный сервер на `127.0.0.1` со случайным токеном в адресе.
Без токена любой запрос получает `403`, поэтому чужая страница в браузере не
может ни запустить прогон, ни прочитать настройки. Ключ API наружу не отдаётся —
в окно приходит только «задан/не задан» и последние 4 символа.


Скачивание, распознавание и вызов модели автотестами не покрыты — нужны сеть и
деньги; проверяются вручную на одном коротком ролике.

## Частые грабли

- **Программа не открылась** — запусти `open "$HOME/Applications/NP Brief.app"`;
  если macOS ругается на неизвестного разработчика, правый клик по приложению →
  «Открыть» → «Открыть».
- **«Не найден yt-dlp»** — запусти установщик ещё раз; площадки меняют выдачу,
  поэтому обновляй его время от времени (тот же скрипт).
- **Instagram отдаёт ошибку** — приватные аккаунты и ролики «только для
  подписчиков» не скачиваются; ссылка должна открываться без входа.
- **Разбор оборвался на лимите длины** — подними `VIDEOBRIEF_MAX_TOKENS` и
  прогони повторно по готовой расшифровке: `--transcript .../transcript.timed.txt`.
- **Текст ролика — это чужой текст.** Программа даёт разбор и каркас, а не
  разрешение копировать дословно; раздел «Чего не копировать» в `brief.md` про это.
