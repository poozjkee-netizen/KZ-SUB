# Качество казахского ASR

Статус: 🟡 Базовая модель работает · развитие
Приоритет: **P1**
Зависимости: [06-analytics](06-analytics.md) (замер WER — общий инструмент)

← [Индекс проекта (PROJECT.md)](../PROJECT.md)

## Цель

Сделать качество распознавания казахского **моутом** продукта: субтитры точнее и
чище, чем у любого «обёрточного» конкурента. По CLAUDE.md это ядро ценности —
панель копируется за неделю, хорошая модель — нет.

## Описание

Сейчас в проде Whisper `large-v3`, язык `kk`, с нарезкой и базовой стилизацией
(регистр/пунктуация) плюс постобработка на шлюзе (`app/postprocess.py`): фильтр
зацикливаний модели и пользовательский словарь правок. Инструмент замера WER/CER
готов (`app/wer.py`), но baseline на реальных роликах ещё не снят — нужны
эталонные транскрипты. Долгосрочный отрыв даёт собственный датасет
казахской речи + fine-tune. Вся серверная логика катится без переустановки
панели — предпочитаем делать здесь.

## Подзадачи

- [x] **Инструмент замера WER/CER** — `app/wer.py` (dep-free): WER, CER, разбор
      ошибок по типам (замены/вставки/удаления), парсер `.srt`, NFC-нормализация,
      CLI `python -m app.wer эталон.txt распознанное.srt`. Гейт для всех правок ниже.
- [ ] **Замер WER baseline** `large-v3` на реальных казахских роликах —
      текст для записи готов ([`docs/samples/asr-test-kk-ru.txt`](../samples/asr-test-kk-ru.txt)),
      пошаговый порядок замера — в [ASR_PROVIDERS.md](../ASR_PROVIDERS.md);
      ждём запись ролика
- [x] **Скрипт локального прогона любой модели** — `scripts/transcribe-local.py`
      гоняет модель тем же конвейером, что и прод (нарезка/стиль/постобработка),
      чтобы сравнение отличалось только моделью
- [x] **Скрипт слияния LoRA-адаптера** — `scripts/merge-lora.py`: многие казахские
      дообучения выложены адаптером (`adapter_config.json` без `config.json`),
      конвертер CTranslate2 такое не берёт. Скрипт сам находит базу, применяет
      `merge_and_unload()` и кладёт процессор/токенизатор (без
      `preprocessor_config.json` faster-whisper падает на 80 мел-каналах)
- [x] **Тайминги: привязка к началу речи** — метки Whisper «спешат» (VAD-паддинг
      + смещение выравнивания), текст выходил раньше произнесённого;
      `app/timing.py` подтягивает начало реплики к фактическому началу речи
      (`KZSUB_SNAP_TO_SPEECH`, `KZSUB_SNAP_WINDOW_SECONDS`)
- [x] **Фильтр зацикливаний Whisper** — модель на тишине печатала одно слово
      десятки раз подряд; `KZSUB_MAX_REPEATS` (по умолчанию 3)
- [x] **Пользовательский словарь** (имена, термины канала) — `KZSUB_LEXICON` /
      `KZSUB_LEXICON_PATH`, замены по границам слов с сохранением регистра,
      пустая правая часть удаляет слово
- [x] **Отсев неправдоподобно долгих реплик** — `KZSUB_MAX_CUE_DROP_SECONDS`
      (по умолчанию выключено: включать под замер WER)
- [ ] **Постобработка текста** (только для режима `phrase` — в караоке-режиме
      пунктуация всё равно снимается):
  - [ ] Восстановление пунктуации
  - [ ] Нормализация чисел, дат, сокращений
- [x] **Параметры декодирования против галлюцинаций и опережения** —
      `transcribe.decode_options()`: `condition_on_previous_text=false`,
      `hallucination_silence_threshold`, пороги no_speech/log_prob/compression,
      `vad_speech_pad_ms=200` вместо 400. **Требует пересборки GPU-образа.**
- [x] **Подсказки модели при декодировании** — `KZSUB_INITIAL_PROMPT` (затравка
      против «оказашивания» русских слов) и `KZSUB_HOTWORDS` (редкие слова/имена).
      По умолчанию пусто: включать и сверять по WER. Требует пересборки образа.
- [ ] **Код-свитчинг каз/рус** — русские слова должны писаться по-русски.
      Затравка выше — дешёвый обход; настоящее решение — модель, обученная на
      смеси (`whisper-turbo-kaz-rus-v1`), см. [ASR_PROVIDERS.md](../ASR_PROVIDERS.md)
- [x] **Разведка альтернатив** — [ASR_PROVIDERS.md](../ASR_PROVIDERS.md): чем
      распознаёт CapCut (свой Seed-ASR от ByteDance, казахский — не приоритет),
      дообученные Whisper на KSC2/каз+рус, ISSAI Soyle, Yandex SpeechKit
      (заявлена смешанная каз-рус речь)
- [x] **Инструмент сравнения моделей** — `python -m app.wer эталон.txt a.srt b.srt …`
      печатает таблицу, отсортированную по WER, с разбором на замены/вставки/пропуски
      и предупреждением, когда пропусков больше 15 % (одинаковый WER бывает у
      моделей с совершенно разным поведением)
- [x] **Прогнать сравнение на своих роликах** — сделано на первом ролике
      (замер в [ASR_PROVIDERS.md §5](../ASR_PROVIDERS.md)): `large-v3` 36.52 % WER /
      12.48 % CER, `ksc2` 36.52 / 24.66, `kaz-rus` 40.87 / 29.02. **Кандидаты
      проиграли, модель не меняем.** Код-свитчинг у всех трёх одинаковый
- [x] **Пропущенные реплики — виноваты наши фильтры, а не модель.** Прогон с
      `--no-filters` вернул пропавшие предложения (97 реплик против 89). Баланс
      сдвинут к полноте: `hallucination_silence_threshold` выключен,
      `log_prob_threshold` `-1.0` → `-1.5` (штатный подобран под английский),
      `vad_threshold` `0.5` → `0.35`. Средства против галлюцинаций, которые
      ничего не удаляют, оставлены. **Требует пересборки GPU-образа.**
- [ ] **Код-свитчинг после снятия фильтров** — `large-v3` пишет русские слова
      «с казахским акцентом». Проверяем затравку `config.MIXED_SPEECH_PROMPT`
      (`scripts/transcribe-local.py --prompt-mixed`); если не помогает —
      словарь частых вставок на шлюзе (`KZSUB_LEXICON`, катится без образа)
- [ ] **Сбор датасета** казахской речи (с согласия пользователей, анонимно) → сервер
- [ ] **Fine-tuning** Whisper на Kazakh Speech Corpus (KSC2) + собранном датасете
- [x] Dep-free тесты: `test_wer.py`, `test_postprocess.py`, `test_timing.py`,
      `test_transcribe_options.py`

## Definition of Done

- Есть воспроизводимый замер WER до/после каждого улучшения (регресс не проходит).
- Постобработка и словарь включаемы через `config.py` (`KZSUB_*`) и покрыты тестами.
- Сформулирована и запущена стратегия датасета/fine-tune как долгосрочный отрыв.

## Заметки

- **Постобработка живёт на шлюзе, не в воркере.** Так правки катятся одним
  `fly deploy`, тогда как те же изменения внутри воркера потребовали бы
  пересборки Docker-образа и смены образа у эндпоинта Runpod.
- Порядок работы над качеством: получить `.srt` до правки → замерить WER →
  внести правку → сравнить. Без цифр улучшение недоказуемо, регресс не виден.
- Развилка STATUS §7.4: начать ли копить датасет с первого дня — да, это то, что конкурент не скопирует быстро.
- Модель не покидает инфраструктуру (серверная обработка) — часть моута.
- Постобработку держим на бэкенде: катится без новой `.zxp`.
- Замер WER пересекается с [06-analytics](06-analytics.md) (метрика удержания).
