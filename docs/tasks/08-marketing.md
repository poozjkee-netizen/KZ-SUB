## Цель

Привлечь пользователей по каналам, где живёт ЦА (казахоязычные видеомейкеры):
органика в экосистеме Adobe, прямые продажи через демо и работа с инфлюенсерами.

## Описание

Каналы описаны в [MONETIZATION.md](../MONETIZATION.md) («Дистрибуция») и ROADMAP
«Этап 5». Прямая раздача `.zxp` уже работает ([DISTRIBUTION.md](../DISTRIBUTION.md));
дальше — масштабируемые каналы обнаружения и доверия.

## Подзадачи

- [ ] **Adobe Exchange Marketplace** — публикация (органическое обнаружение внутри Adobe, доверие; нужен подписанный `.zxp` + их ревью)
- [x] **Лендинг** — `site/index.html`: один самодостаточный файл без сборки,
      кладётся на любой хостинг копированием. Структура ведёт к одной цели —
      кнопке «Взять демо» в Telegram-боте: проблема → как работает → пример
      вывода `.srt` со смешанной каз-рус речью → возможности → тариф → вопросы.
      Два языка (қаз/рус) с переключателем в шапке — все тексты в словаре `I18N`
      внизу файла. Мобильная вёрстка с закреплённой панелью действия.
      Бот `@np_subbot`, почта `poozjkee@gmail.com`.
      **Осознанно без выдуманных отзывов, логотипов и счётчиков пользователей:**
      фальшивое социальное доказательство на маленьком рынке вычисляется мгновенно
      и стоит дороже, чем даёт
- [ ] **Демо-ролики «до/после»** для лендинга — нужен твой экранный захват
      реального прогона в Premiere (сейчас на странице честный текстовый пример)
- [ ] **Инфлюенсеры** — казахоязычные ютуберы/тиктокеры (они же ЦА и канал)
- [ ] Демо-материалы: короткие ролики «до/после» распознавания
- [ ] Мессадж/позиционирование: «Premiere не умеет казахский — а мы умеем»

## Definition of Done

- Есть хотя бы один работающий канал привлечения с измеримым притоком (см. [06-analytics](06-analytics.md): конверсия).
- Демо «до/после» на казахском готово и используется в лендинге/у инфлюенсеров.
