## Цель

Привлечь пользователей по каналам, где живёт ЦА (казахоязычные видеомейкеры):
органика в экосистеме Adobe, прямые продажи через демо и работа с инфлюенсерами.

## Описание

Каналы описаны в [MONETIZATION.md](../MONETIZATION.md) («Дистрибуция») и ROADMAP
«Этап 5». Прямая раздача `.zxp` уже работает ([DISTRIBUTION.md](../DISTRIBUTION.md));
дальше — масштабируемые каналы обнаружения и доверия.

## Подзадачи

- [ ] **Adobe Exchange Marketplace** — публикация (органическое обнаружение внутри Adobe, доверие; нужен подписанный `.zxp` + их ревью)
- [x] **Лендинг** — `site/index.html`: один самодостаточный файл без сборки,
      кладётся на любой хостинг копированием. Структура ведёт к одной цели —
      кнопке «Взять демо» в Telegram-боте: проблема → как работает → пример
      вывода `.srt` со смешанной каз-рус речью → возможности → тариф → вопросы.
      Два языка (қаз/рус) с переключателем в шапке — все тексты в словаре `I18N`
      внизу файла. Мобильная вёрстка с закреплённой панелью действия.
      Бот `@np_subbot`, почта `poozjkee@gmail.com`.
      **Осознанно без выдуманных отзывов, логотипов и счётчиков пользователей:**
      фальшивое социальное доказательство на маленьком рынке вычисляется мгновенно
      и стоит дороже, чем даёт
- [x] **Публикация на GitHub Pages** — `.github/workflows/pages.yml` публикует
      `site/` при каждом пуше в ветку по умолчанию. Включить один раз:
      Settings → Pages → Source: GitHub Actions. Для приватного репозитория
      Pages требует платного плана — иначе Cloudflare Pages / Netlify
- [x] **Демо-видео в геройском блоке** — `site/np-sub-animation.mp4`. Место под
      видео зарезервировано через `aspect-ratio`, блок виден всегда и прячется
      только при настоящей ошибке загрузки — так исправлен баг, из-за которого
      видео (и подпись к нему) не появлялось на мобильных: раньше блок
      открывался лишь по событию `loadeddata`, а iOS на сотовых данных часто
      игнорирует `preload` и это событие не приходит вовсе
- [x] **Проверка мобильной вёрстки в браузере** — прогон через Chromium (CDP):
      375/390/412/768/1440 px, замер горизонтальной прокрутки, размера текста и
      целей нажатия. Нашлись и исправлены: цели меньше 44 px на сенсорных
      экранах, и — важнее — контент ниже первого экрана был виден только при
      работающем JS (теперь появление блоков включается меткой `js`)
- [x] **Раздача установщика** — `site/download/NP-SUB-installer.zip` (постоянное
      имя без версии, чтобы ссылка не ломалась при обновлении). На лендинге —
      секция «Установка» с тремя шагами, в боте — команда `/download` и кнопка
      под сообщением с ключом. Бот шлёт файл в чат (Telegram забирает по URL),
      при недоступности хостинга — ссылкой
- [ ] **Инфлюенсеры** — казахоязычные ютуберы/тиктокеры (они же ЦА и канал)
- [ ] Демо-материалы: короткие ролики «до/после» распознавания
- [ ] Мессадж/позиционирование: «Premiere не умеет казахский — а мы умеем»
