## Цель

Расширить продукт за пределы казахского и текущей платформы CEP, когда ядро
(казахский ASR + продажи) устоится. В шапке панели языки уже помечены «скоро» —
это обещание, которое v2 выполняет.

## Описание

Собирает крупные будущие направления, не входящие в ближайший запуск: соседние
языки Центральной Азии (та же боль — их тоже нет «из коробки») и портирование
панели на UXP, когда та созреет для Premiere.

## Подзадачи

- [ ] **Кыргызский** язык (в шапке уже «скоро»)
- [ ] **Узбекский** язык (в шапке уже «скоро»)
- [ ] Для каждого нового языка: замер WER, постобработка, словарь (по образцу [04-asr-quality](04-asr-quality.md))
- [ ] **Портирование панели CEP → UXP** (когда UXP созреет для Premiere)
- [ ] Оценка спроса по каждому направлению перед реализацией

## Definition of Done

- Хотя бы один новый язык доведён до качества, сопоставимого с казахским (по WER), и снят статус «скоро» в шапке.
- Решение по UXP принято на основе зрелости платформы, а не преждевременно.

## Заметки

- Новый язык — серверная фича: катится без новой `.zxp` (кроме снятия метки «скоро» в шапке).
- Не начинать, пока казахский ASR и продажи не устоялись — это отвлекает от моута.
- Годовые тарифы/промо относятся к [03-sales-automation](03-sales-automation.md), не сюда.
