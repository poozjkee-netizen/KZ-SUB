## Цель

Панель — тонкий, понятный клиент: одна кнопка, техника спрятана, ошибки на
понятном языке. Довести до состояния, где пользователь сам видит баланс минут и
управляет тарифом, не выходя из Premiere.

## Описание

CEP-панель (HTML/CSS/ES5-JS + ExtendScript). Версия 1.4.0 уже даёт гейт
активации, прогресс по этапам, полную локализацию (ru/kk) и валидацию ключа.
Любое изменение панели требует новой `.zxp` и переустановки у пользователя (см.
[DISTRIBUTION.md](../DISTRIBUTION.md)) — поэтому логику по возможности держим на
сервере. Ручное тестирование — по [RUNBOOK.md](../RUNBOOK.md).

## Подзадачи

- [x] Гейт активации при первом запуске (ключ обязателен, сохраняется)
- [x] «Проверить» валидирует сам ключ (статус/остаток минут/причина отказа)
- [x] Прогресс обработки по этапам с процентами
- [x] Полная локализация интерфейса (единый словарь `js/i18n.js`, ru/kk)
- [x] Язык субтитров в шапке / язык интерфейса в настройках; footer «powered by danik np»
- [x] Анти-шаринг: отпечаток устройства `X-Device-Id`
- [x] **Баланс минут в панели** — плашка в шапке рядом с выбором языка: из `X-Minutes-Remaining` после прогона и из `GET /license` при открытии/активации/проверке
- [ ] **Личный кабинет:** тип лицензии и срок действия рядом с балансом
- [ ] **Экран смены тарифа** (апгрейд/даунгрейд) — завязан на `change_plan` из [02-licensing](02-licensing.md)
- [ ] **Регистрация** из панели (`POST /register` → trial-ключ на почту)
- [ ] Реальный прогресс вместо «якорей»-этапов (по возможности)
- [ ] Выбор части секвенции (in/out) вместо всей

## Definition of Done

- Пользователь видит остаток минут и статус лицензии прямо в панели.
- Смена тарифа/регистрация доступны из UI и корректно бьются с бэкендом.
- Контракт с бэкендом (заголовки `X-API-Key`/`X-Device-Id`, multipart `file`, ID DOM-элементов) не нарушен.

## Заметки

- ES5-совместимость (старый CEF), без сборщиков/CDN, всё локально (офлайн-устойчивость).
- Каждая правка панели = новая версия в манифесте + пересборка `.zxp` (переустановка у клиента).
- Проверка 1.4.0 в живом Premiere — в [01-commercial-launch](01-commercial-launch.md).
- Портирование CEP → UXP отложено в [09-v2](09-v2.md).
