## Цель

Довести продукт до первой реальной продажи: проверить панель 1.2.0 в живом
Premiere, задеплоить актуальный шлюз и прогнать полный цикл ручной продажи
через Kaspi (оплата → выдача ключа → рабочий клиент).

## Описание

Код и инфраструктура готовы (см. [PROJECT.md](../PROJECT.md)): транскрибация
казахского работает в проде (~20–30 с), лицензии и CLI-выдача настроены,
ручной Kaspi-runbook описан в [DISTRIBUTION.md](../DISTRIBUTION.md). Остались
«реальные» действия, которые нельзя сделать из кода: собрать/поставить `.zxp`,
проверить его в Premiere и провести пробную продажу. Это финальный гейт перед
тем, как звать первых платящих пользователей.

## Подзадачи

- [ ] **Собрать `.zxp` 1.2.0** — `ZXPSIGNCMD=~/bin/ZXPSignCmd bash scripts/build-zxp.sh` → `dist/NP-SUB-1.2.0.zxp`
- [ ] **Задеплоить шлюз** — `fly deploy --remote-only`, чтобы новый CLI (`plans`/`create --plan`/`delete`/`purge-revoked`) был в контейнере
- [ ] **Проверить панель в Premiere** (чек-лист):
  - [ ] Гейт активации отклоняет неверный ключ, пускает верный
  - [ ] «Проверить» показывает статус лицензии и остаток минут
  - [ ] Переключение языка интерфейса (ru/kk) сохраняется между запусками
  - [ ] Прогресс идёт по этапам с процентами
  - [ ] Субтитры казахской речи ложатся на новую дорожку
- [ ] **Пробная продажа** (runbook из DISTRIBUTION.md):
  - [ ] Kaspi-оплата по тарифу (тестовая)
  - [ ] `python -m app.licenses create --email … --plan starter`
  - [ ] Отправить клиенту ключ + `.zxp` + инструкцию (Часть 2 DISTRIBUTION.md)
  - [ ] Подтвердить, что клиент активировал и получил субтитры
- [ ] **Подготовить тестовые казахские аудио-сэмплы** для быстрой проверки прогонов

## Definition of Done

- `.zxp` 1.2.0 установлен и полностью проверен в реальном Premiere (все пункты чек-листа зелёные).
- Шлюз задеплоен, CLI в контейнере актуален.
- Проведён минимум один полный цикл продажи (пусть тестовый) от оплаты до рабочих субтитров у клиента.
