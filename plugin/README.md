# NP SUB Plugin (CEP-панель для Premiere Pro)

Панель, которая выгружает аудио активной секвенции, отправляет его на
[бэкенд NP SUB](../backend/README.md), получает казахские субтитры и
импортирует их обратно в проект Premiere.

## Технология
- **CEP** (Common Extensibility Platform) — HTML/CSS/JS панель + ExtendScript.
- Выбран CEP, а не UXP: для Premiere UXP ещё незрелый, а CEP даёт полный
  доступ к секвенциям и экспорту/импорту. Переход на UXP — в roadmap.

## Файлы
| Путь                     | Назначение                                        |
|--------------------------|---------------------------------------------------|
| `CSXS/manifest.xml`      | описание расширения (host PPRO)                   |
| `index.html`             | UI панели                                         |
| `css/style.css`          | стили                                             |
| `js/main.js`             | логика: экспорт → загрузка → импорт               |
| `js/i18n.js`             | единый словарь переводов (ru/kk) + `I18N.t()` — все видимые строки |
| `js/CSInterface.js`      | минимальный шим CEP (встроен; можно заменить официальным) |
| `jsx/host.jsx`           | ExtendScript: экспорт аудио, выбор пресета, импорт .srt (возвращает коды) |
| `.debug`                 | порт удалённой отладки                            |

## Аудио-пресет (.epr)
Экспорт секвенции в Premiere требует пресета (ограничение Adobe, бинарник
нельзя сгенерировать кодом). Его **не нужно копировать в папку плагина** —
выберите `.epr` прямо в панели кнопкой **«Таңдау»** (путь запоминается).
Как создать пресет один раз — см. [`presets/README.md`](presets/README.md).

## Установка (режим разработки)

### 1. Включить debug-режим CEP (неподписанные расширения)
- **macOS:** `defaults write com.adobe.CSXS.11 PlayerDebugMode 1`
- **Windows:** в реестре `HKEY_CURRENT_USER\Software\Adobe\CSXS.11`
  строковый параметр `PlayerDebugMode = 1`

> Номер (`CSXS.11`) зависит от версии Premiere. Для новых версий может быть
> `CSXS.12`. Поставьте флаг для той версии, что используете.

### 2. Положить панель в папку расширений
Скопируйте (или симлинкните) папку `plugin/` как `kz.kzsub.panel` в:
- **macOS:** `~/Library/Application Support/Adobe/CEP/extensions/`
- **Windows:** `%APPDATA%\Adobe\CEP\extensions\`

### 3. Запустить и настроить
Premiere → **Window → Extensions → NP SUB**:
1. Укажите **API URL** и **API-кілт**, нажмите **«Тест»** — убедитесь, что сервер отвечает.
2. Кнопкой **«Таңдау»** выберите аудио-пресет `.epr` (один раз).
3. Откройте секвенцию, нажмите **«Субтитр жасау»**.

## Дистрибуция (прод)
Для установки у пользователей без debug-режима панель нужно **подписать**
(`.zxp`) с помощью `ZXPSignCmd` и выложить на **Adobe Exchange**. См.
[`docs/ROADMAP.md`](../docs/ROADMAP.md).

## Вставка на таймлайн
Плагин пытается положить субтитры на **новую верхнюю видеодорожку** (через QE
DOM + `insertClip`) — недеструктивно, существующие клипы не сдвигаются и не
перезаписываются, всё отменяется Cmd+Z. Если API конкретной версии Premiere не
даёт добавить дорожку/вставить, происходит **безопасный откат**: ассет остаётся
в корзине проекта, и панель просит перетащить его вручную.

## Известные ограничения (MVP)
- Авто-вставка зависит от версии Premiere (QE DOM недокументирован). При сбое —
  откат в корзину (не ломает таймлайн).
- Требуется один раз созданный `.epr` аудио-пресет (выбирается кнопкой в панели).
- `CSInterface.js` — минимальный шим (нужного нам API достаточно). При
  необходимости расширенного функционала замените официальным файлом Adobe.
