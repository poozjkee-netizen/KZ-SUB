# Аудио-пресет экспорта (`audio_wav.epr`)

Premiere не умеет экспортировать секвенцию **без пресета**, а бинарный `.epr`
нельзя сгенерировать кодом. Поэтому пресет нужно создать один раз вручную:

1. В Premiere: **File → Export → Media** (любая секвенция).
2. Format: **Waveform Audio (WAV)**.
3. Preset: моно/стерео, 16 kHz или 16 bit — для ASR достаточно **16 kHz, mono**
   (меньше файл, быстрее загрузка; Whisper всё равно ресемплит в 16 kHz).
4. Нажмите иконку **Save Preset**, назовите, например, `KZSUB Audio 16k`.
5. Сохранённый `.epr` лежит в системной папке пресетов Adobe. Скопируйте его
   сюда как `audio_wav.epr` — плагин ищет именно этот путь
   (`plugin/presets/audio_wav.epr`).

> Позже пресет можно приложить к дистрибутиву плагина, чтобы пользователю не
> нужно было создавать его вручную.
