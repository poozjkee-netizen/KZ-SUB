# Аудио-пресет экспорта (`audio_wav.epr`)

Пресет **уже вложен** (`audio_wav.epr`) — новому пользователю ничего создавать
не нужно, плагин берёт его по умолчанию. Premiere не умеет экспортировать
секвенцию без пресета, поэтому он и нужен.

## Параметры вложенного пресета
- Формат: **WAV** (audio only, без видео).
- **16 kHz, моно** — Whisper всё равно работает на 16 kHz mono, а размер
  выгружаемого аудио при этом в ~6 раз меньше, чем 48 kHz стерео (важно для
  лимита размера запроса на бэкенде и для длинных видео).

## Если нужно пересоздать вручную
1. В Premiere: **File → Export → Media** (любая секвенция).
2. Format: **Waveform Audio (WAV)**, Sample Rate **16000 Hz**, Channels **Mono**.
3. **Save Preset** → скопировать `.epr` сюда как `audio_wav.epr`.
