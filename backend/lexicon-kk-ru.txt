# Словарь правок для казахско-русской смешанной речи (NP SUB).
#
# Зачем: модель распознаёт с language=kk и записывает проскочившее русское
# слово казахской орфографией — «КЫСТАТИ» вместо «КСТАТИ». Затравка и подсказки
# декодера уменьшают это, но не до нуля, поэтому хвост подчищаем здесь.
#
# Почему на шлюзе, а не в воркере: правки катятся одним `fly deploy`, без
# пересборки GPU-образа и без новой .zxp у пользователя. Список пополняется по
# мере того, как в субтитрах попадаются новые «оказашенные» слова.
#
# Формат: было=стало, по строке на правило. Регистр не важен: сравнение
# регистронезависимое, а регистр исходного слова сохраняется (в караоке-режиме
# субтитры печатаются капсом — замена тоже станет капсом). Совпадение идёт по
# границам слова, поэтому «кстати» внутри другого слова не заденет.
# Пустая правая часть удаляет слово: «мусор=».
#
# Подключение:
#   fly secrets set KZSUB_LEXICON_PATH=/app/lexicon-kk-ru.txt
# либо теми же правилами через KZSUB_LEXICON (через запятую).

# --- вводные слова, самые частые в разговорной речи ---
қыстати=кстати
кыстати=кстати
кәнешне=конечно
канешне=конечно
кәнечно=конечно
вабще=вообще
уабще=вообще
кәроче=короче
короше=короче
напримыр=например
прошта=просто

# --- служебные обороты ---
и бәрі готово=и всё готово
всо готово=всё готово
